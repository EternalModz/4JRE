# 4JRE
A Minecraft PlayStation®3 CodeLib/Docs repo. 4JRE will hold research, example code, and addresses.

# Requirements
#### To Compile
1. PlayStation 4.75 SDK + ProDG Target Manager
2. Visual Studio 2010+ w/ SDK Integration

### Reversing/Development
1. Reversing Software *Ghidra, IDA, etc.*
2. PS3 Debugging Software *ProDG provides one, Universal Debugger by MayhemModding works as well.*
